# Documentation des appareils

Créer ici une fiche Markdown par appareil, par exemple `capteur-salon.md` :

- nom du fichier YAML correspondant à la racine ;
- référence exacte de la carte et du microcontrôleur ;
- capteurs, câblage et numéros des GPIO ;
- alimentation et méthode de premier flash ;
- rôle des entités et particularités de fonctionnement.

Les mots de passe et clés restent dans `secrets.yaml`. Les sauvegardes binaires
de cartes restent dans `backups/`, exclu du dépôt Git.
